# Size Chart Management

The Size Chart extension is an essential capability for apparel, footwear, and lifestyle merchants. It provides interactive measurement charts and measuring guides directly on product pages, boosting buyer confidence and drastically reducing sizing-related product returns.

---

## 1. Creating a Size Chart

1. In the admin menu, open **Size Chart**.
2. Click **Create**.
3. Configure the chart parameters:
   - **Internal Name**: (e.g., "Men's Slim Fit Shirts", "Running Shoes EU / US Conversion").
   - **Units & Measurement Columns**: Choose Centimeters (cm) or Inches (in), adding relevant dimension columns (Chest, Waist, Inseam, Sleeve Length, Hip).
   - **Rows & Sizes**: Fill in dimension values for standard sizes (XS, S, M, L, XL, XXL).
   - **How-to-Measure Visual Guide**: Upload an anatomical diagram showing shoppers where to measure their body.

---

## 2. Assigning Charts to Categories and Products

- **Category-Level Assignment**: Link a chart to an entire catalog category (e.g., Men >> Tops >> T-Shirts) to automatically render across all items under that branch.
- **Product Override**: Assign custom size charts to individual products from their catalog edit screens when specialized sizing applies.

---

## 3. Storefront Shopper Experience

- On the product detail page, a stylish **Size Guide / Size Chart** link appears right beside variant size swatches.
- Clicking opens a clean modal popup presenting the dimension matrix alongside visual measurement instructions.
