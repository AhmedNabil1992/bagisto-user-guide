# أنواع إدخال السمات

لكل سمة نوع خاص بها. يحدد النوع ما تملؤه في شاشة تعديل المنتج، مثل مربع نص، أو مفتاح تبديل، أو قائمة خيارات، بالإضافة إلى الإعدادات التي يمكن أن تستخدمها السمة. تختار النوع عند [إنشاء السمة](./product-attribute.md)، ولا يمكنك تغييره لاحقاً.

## الأنواع {#the-types}

توفر قائمة **نوع السمة** هذه الأنواع، بهذا الترتيب:

| النوع | في شاشة تعديل المنتج | استخدامه |
|---|---|---|
| **نص (Text)** | مربع نص من سطر واحد. | للقيم القصيرة، مثل رقم الطراز. |
| **منطقة نص (Textarea)** | مربع نص متعدد الأسطر، أو محرر نصوص منسقة عند تفعيل **تمكين محرر WYSIWYG**. | للنصوص الأطول، مثل إرشادات العناية. |
| **سعر (Price)** | مبلغ بجانب رمز عملتك الأساسية. ويجب أن يكون رقماً. | للمبالغ الإضافية، مثل سعر البيع المقترح بالتجزئة. |
| **قيمة منطقية (Boolean)** | مفتاح تبديل (تفعيل أو تعطيل). | للحقائق الثنائية (نعم أو لا)، مثل ما إذا كانت السترة مقاومة للماء. |
| **مربع اختيار (Checkbox)** | مربع اختيار لكل خيار متاح. يمكنك تحديد أي عدد منها. | للميزات، مثل الغرف التي تناسبها وحدة الإضاءة. |
| **قائمة منسدلة (Select)** | قائمة خيارات تختار منها خياراً واحداً. | للاختيارات الفردية مثل اللون أو المقاس أو العلامة التجارية. |
| **تحديد متعدد (Multiselect)** | قائمة خيارات تختار منها خياراً واحداً أو أكثر. | لعدة قيم في وقت واحد، مثل الفصول التي يناسبها المعطف. |
| **تاريخ (Date)** | منتقي تاريخ. | للتواريخ، مثل تاريخ الإصدار. |
| **تاريخ ووقت (Datetime)** | منتقي تاريخ ووقت. | للمواعيد الدقيقة، مثل موعد بدء فعالية حية. |
| **صورة (Image)** | مربع **إضافة صورة** يقبل ملفات BMP أو JPEG أو JPG أو PNG أو WEBP. | لصورة، مثل جدول المقاسات. |
| **ملف (File)** | مربع **إضافة ملف** يقبل رفع ملف. | لمستند، مثل دليل المستخدم. |

بعد رفع الملف، يعرض مربع **الصورة** معاينة لها، بينما يعرض مربع **الملف** اسم الملف المرفوع. عند الإشارة إلى المربع تظهر أيقوناته: **استبدال** لاختيار ملف آخر، **تنزيل** لتنزيل الملف المحفوظ، و**حذف** لإزالته. لا يتوفر خيار **حذف** طالما أن خيار **مطلوب** مفعل في السمة. يتم حفظ التغييرات عند حفظ المنتج.

## الإعدادات التي يدعمها كل نوع {#settings-each-type-supports}

لا يمكن استخدام بعض الإعدادات إلا مع أنواع معينة. وتكون مخفية، أو غير مفعلة (باللون الرمادي)، أو يتم تجاهلها عند الحفظ بالنسبة للأنواع الأخرى:

| الإعداد | الأنواع المدعومة |
|---|---|
| **الخيارات** | مربع اختيار (Checkbox)، قائمة منسدلة (Select)، وتحديد متعدد (Multiselect). تقوم بإضافة الخيارات بنفسك. |
| **خيارات الإدخال** | قائمة منسدلة (Select). يمكن عرض الخيارات كقائمة منسدلة، أو كعينات ألوان أو صور أو نصوص. |
| **الاستخدام في التصفح متعدد الطبقات** | مربع اختيار، قائمة منسدلة، تحديد متعدد، قيمة منطقية، وسعر. |
| **الاستخدام لإنشاء منتج قابل للتهيئة** | قائمة منسدلة (Select). |
| **تمكين محرر WYSIWYG** | منطقة نص (Textarea). |
| **القيمة الافتراضية** | قيمة منطقية (Boolean). |
| **التحقق من صحة الإدخال** | نص (Text). |
| **القيمة لكل لغة** | جميع الأنواع باستثناء مربع الاختيار والقائمة المنسدلة والتحديد المتعدد والقيمة المنطقية. حيث تترجم سمات مربع الاختيار والقائمة المنسدلة والتحديد المتعدد أسماء خياراتها بدلاً من ذلك، بينما تعرض سمات القيمة المنطقية **نعم** أو **لا**. |

أما الإعدادات الأخرى، مثل **مطلوب** و**القيمة لكل قناة**، فتظهر لجميع الأنواع. يشرح دليل [سمات المنتجات](./product-attribute.md) وظيفة كل إعداد.

## ما يراه المتسوقون {#what-shoppers-see}

عند تفعيل خيار **الاستخدام في التصفح متعدد الطبقات**، يمكنك تحديد السمة ضمن **السمات القابلة للتصفية** الخاصة بالفئة، لتصبح فلتر تصفية في صفحة تلك الفئة. كما توفر نتائج البحث كل سمة من هذا القبيل كفلتر. تظهر سمة **السعر** كشريط تمرير لتحديد النطاق، بينما تعرض الأنواع الأخرى خياراتها كمربعات اختيار.

بالنسبة لسمة **القائمة المنسدلة (Select)** التي تستخدمها المنتجات القابلة للتهيئة لمتغيراتها، يحدد إعداد **خيارات الإدخال** كيفية اختيار المتسوقين للمتغير في صفحة المنتج:

| خيارات الإدخال | ما يراه المتسوقون |
|---|---|
| **قائمة منسدلة (Dropdown)** | قائمة منسدلة بالخيارات المتاحة. |
| **عينة لون (Color Swatch)** | دائرة ملونة لكل خيار. |
| **عينة صورة (Image Swatch)** | صورة مصغرة لكل خيار. |
| **عينة نص (Text Swatch)** | زر يحمل تسمية كل خيار. |

## حجم رفع سمات الصور والملفات {#upload-size-of-image-and-file-attributes}

يتم ضبط الحد الأقصى لحجم الصورة أو الملف الذي يمكنك رفعه لسمة من نوع **صورة** أو **ملف** ضمن **التكوين >> الكتالوج >> المنتجات**. راجع [السمة](../configure/attribute.md).
