# المهام المجدولة (Scheduled Tasks)

تتم بعض عمليات المتجر وفق جدول زمني محدد أو في الخلفية دون الحاجة لضغط أزرار من لوحة التحكم؛ مثل إعادة احتساب أسعار قواعد الكتالوج ليلاً، إرسال الحملات البريدية اليومية، ومعالجة رسائل البريد الإلكتروني عبر طابور الانتظار (Queue) لضمان سرعة تصفح المتجر.

لا يتم ضبط هذه المهام من لوحة التحكم، بل يضبطها مطور المتجر أو موفر الاستضافة على الخادم (Server) لضمان استقرار العمليات التلقائية.

## متطلبات الخادم الأساسية

- **مجدول المهام (Laravel Scheduler - Cron Job)**: يشغل الخادم أمر مجدول باجيستو كل دقيقة ليقوم المجدول ببدء كل مهمة في وقتها المحدد تلقائياً.
- **عامل طابور الانتظار (Queue Worker)**: لمعالجة المهام الثقيلة في الخلفية (مثل إرسال البريد وفهرسة المنتجات الكثيرة) دون تعطيل أو إبطاء تصفح المتسوقين لواجهة المتجر.

## المهام التي تعمل وفق جدول زمني محدد

| المهمة | متى تعمل؟ | القسم المرتبط |
|---|---|---|
| إعادة احتساب أسعار قواعد الكتالوج وبدء وانتهاء الخصومات | كل ليلة، بعد منتصف الليل مباشرة | [قواعد الكتالوج](../marketing/catalog-rules.md) |
| تحديث فهرس أسعار المنتجات المستخدم للفرز والفلترة | كل ليلة، بعد منتصف الليل | [قواعد الكتالوج](../marketing/catalog-rules.md) |
| إرسال رسائل الحملات التسويقية التي حان موعدها | مرة يومياً عند منتصف الليل | [الحملات](../marketing/campaigns.md) |
| إرسال رسائل تذكيرية للفواتير المتأخرة | يومياً في تمام الساعة 3:00 صباحاً | [إعدادات الفواتير](../configure/invoice-settings.md) |
| تسجيل أقل سعر للمنتجات وحذف السجلات القديمة | كل 15 دقيقة، مع تنظيف يومي | [الإفصاح عن الأسعار (Omnibus)](../configure/omnibus.md) |
| التحديث التلقائي لأسعار الصرف من المزود | يومياً أو أسبوعياً أو شهرياً حسب اختيارك | [أسعار الصرف](../configure/exchange-rates-configurations.md) |

تتبع جميع المواعيد المنطقة الزمنية المحددة لمتجرك.

## المهام التي تتم عبر طابور الانتظار (Queue)

- إرسال كافة رسائل البريد الإلكتروني (تأكيد الطلب، الفاتورة، التسجيل، الحملات).
- تحديث الأسعار والمخزون في الخلفية بعد حفظ منتج أو قاعدة أسعار.
- فهرسة المنتجات لمحركات البحث المتقدمة (مثل Elasticsearch).
- تسجيل عمليات بحث المتسوقين الأكثر تكراراً.
- معالجة عمليات الاستيراد الضخمة للمنتجات والعملاء.
- توليد وتحديث ملفات خريطة الموقع (Sitemap).

## مؤشرات وجود مشكلة في عمل المهام بالخلفية

| الملاحظة | السبب المحتمل |
|---|---|
| تأخر وصول رسائل البريد أو عدم وصولها | توقف عامل الطابور (Queue Worker) |
| خصم الكتالوج لا يظهر أو لا ينتهي في موعده المحدد | توقف مجدول المهام (Scheduler) |
| عدم إرسال الحملات التسويقية | توقف المجدول أو عامل الطابور |
| بقاء عمليات استيراد المنتجات معلقة بنفس النسبة | توقف عامل الطابور (Queue Worker) |
| عدم تحديث أسعار الصرف التلقائية | توقف مجدول المهام (Scheduler) |

عند ملاحظة أي من هذه الأعراض، يرجى التواصل مع مطور المتجر أو الدعم الفني للتأكد من تشغيل أمر `php artisan schedule:run` كل دقيقة وخدمة `queue:work`.
