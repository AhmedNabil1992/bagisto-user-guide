# السمات

تتيح لك سمات المنتجات من نوعي **الصورة (Image)** و**الملف (File)** رفع ملفات ضمن نموذج إنشاء وتعديل المنتج. يحدد قسم **السمة (Attribute)** الحد الأقصى لحجم تلك الملفات المرفوعة.

1. انتقل إلى **التكوين >> الكتالوج >> المنتجات** (Configure >> Catalog >> Products).
2. في قسم **السمة** (Attribute)، أدخل **حجم رفع الصور المسموح به (بالكيلوبايت)** (Allowed Image Upload Size (in Kb)).
3. أدخل **حجم رفع الملفات المسموح به (بالكيلوبايت)** (Allowed File Upload Size (in Kb)).
4. انقر على **حفظ التكوين**.

<ImagePopup src="/images/configure/products-attribute.png" alt="قسم السمة في شاشة المنتجات مع حدود حجم الرفع" />

يتم إدخال الأحجام بالكيلوبايت، حيث تعني القيمة `2048` السماح برفع ملفات بحجم يصل إلى 2 ميجابايت. إذا لم يتم حفظ أي حجم، فإن الحد الافتراضي هو `2048`. يحدد حقل **حجم رفع الملفات المسموح به (بالكيلوبايت)** أيضاً الحد الأقصى لـ [مقاطع الفيديو المرفوعة إلى المنتج](../product-types/products.md#videos). تنطبق هذه الإعدادات على المتجر بأكمله.

تم شرح أنواع السمات بالتفصيل في [أنواع مدخلات السمات](../attribute/attribute-input.md).
