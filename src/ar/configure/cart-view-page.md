# صفحة عرض سلة التسوق

يمكن لصفحة سلة التسوق اقتراح منتجات البيع العابر (Cross-Sell) أسفل العناصر الموجودة في السلة. يحدد قسم **تكوين صفحة عرض سلة التسوق** (Cart view page configuration) عدد تلك المنتجات المعروضة.

1. انتقل إلى **التكوين >> الكتالوج >> المنتجات** (Configure >> Catalog >> Products).
2. في قسم **تكوين صفحة عرض سلة التسوق** (Cart view page configuration)، أدخل **العدد المسموح به لمنتجات البيع العابر** (Allowed number of Cross-Sell Products).
3. انقر على **حفظ التكوين**.

<ImagePopup src="/images/configure/products-cart-view-page.png" alt="قسم تكوين صفحة عرض سلة التسوق في شاشة المنتجات" />

اترك الحقل فارغاً لعرض جميع المنتجات المرتبطة، أو أدخل `0` لمنع عرض أي منها.

تُستمد هذه الاقتراحات من منتجات البيع العابر المحددة لكل منتج مضاف إلى السلة، مع استبعاد أي منتجات مضافة بالفعل داخل السلة. يتم تحديد منتجات البيع العابر في صفحة كل منتج؛ راجع [المنتجات](../product-types/products.md#related-up-sell-and-cross-sell-products). ولا تظهر هذه الاقتراحات إلا عند تفعيل خيار **منتجات البيع العابر** ضمن إعدادات [إتمام الطلب](./checkout.md). ينطبق هذا الإعداد على المتجر بأكمله.
