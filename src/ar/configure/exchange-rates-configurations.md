# أسعار الصرف

يمكن لـ Bagisto جلب أسعار الصرف الحالية تلقائياً عبر خدمات تتبع أسعار العملات، لتبقى الأسعار المعروضة بعملاتك الأخرى دقيقة دون الحاجة لتحديثها يدوياً. يمكنك تحديث الأسعار عند الطلب فورياً أو وفق جدول زمني تلقائي. تنطبق جميع الإعدادات في هذه الشاشة على المتجر بأكمله.

## الإعدادات العامة

1. انتقل إلى **التكوين >> عام >> أسعار الصرف** (Configure >> General >> Exchange Rates).
2. في قسم **الإعدادات العامة** (General Settings)، اختر **الخدمة الافتراضية** (Default Service): إما **Exchange Rates API** (الافتراضية) أو **Fixer API**.
3. انقر على **حفظ التكوين**.

الخدمة الافتراضية هي التي تُستخدم في عمليات التحديث المجدولة وعند الضغط على زر **تحديث أسعار الصرف**. تأكد من إدخال مفتاح API الخاص بالخدمة التي اخترتها في القسم التابع لها.

## مزود Exchange Rates API

تجلب خدمة [ExchangeRate-API](https://www.exchangerate-api.com) أسعار جميع العملات المحددة في طلب واحد. ستحتاج إلى الحصول على مفتاح API من حسابك على منصة ExchangeRate-API.

1. انتقل إلى **التكوين >> عام >> أسعار الصرف** (Configure >> General >> Exchange Rates).
2. في قسم **Exchange Rates API**، أدخل **مفتاح واجهة التطبيقات** (API Key).
3. انقر على **حفظ التكوين**.

## مزود Fixer API

تطلب خدمة [Fixer](https://fixer.io) سعر الصرف لكل عملة في طلب مستقل. ستحتاج إلى الحصول على مفتاح API من حسابك على منصة Fixer.

1. انتقل إلى **التكوين >> عام >> أسعار الصرف** (Configure >> General >> Exchange Rates).
2. في قسم **Fixer API**، أدخل **مفتاح واجهة التطبيقات** (API Key).
3. انقر على **حفظ التكوين**.

<ImagePopup src="/images/configure/exchange-rates-settings.png" alt="أقسام الإعدادات العامة وExchange Rates API وFixer API مع مفاتيح API تجريبية" />

في حال ترك حقل **مفتاح واجهة التطبيقات** فارغاً، سيعتمد المتجر على المفتاح المحدد لتلك الخدمة في ملف بيئة الخادم (.env) إن وُجد.

## الاستيراد المجدول

1. انتقل إلى **التكوين >> عام >> أسعار الصرف** (Configure >> General >> Exchange Rates).
2. في قسم **الاستيراد المجدول** (Scheduled Import)، قم بتفعيل خيار **تمكين** (Enabled). سيظهر حقلا **التكرار** (Frequency) و**وقت البدء (ساعة:دقيقة)** (Start Time (HH:MM)).
3. حدد **التكرار** (Frequency): **يومياً** (Daily - الافتراضي)، أو **أسبوعياً** (Weekly - يعمل كل يوم اثنين)، أو **شهرياً** (Monthly - يعمل في اليوم الأول من كل شهر).
4. أدخل **وقت البدء (ساعة:دقيقة)** بنظام 24 ساعة، مثل `03:00`. القيمة الافتراضية هي `00:00`.
5. انقر على **حفظ التكوين**.

<ImagePopup src="/images/configure/exchange-rates-schedule.png" alt="قسم الاستيراد المجدول مفعلاً مع ضبط تحديث الأسعار يومياً عند الساعة 03:00" />

تعتمد التحديثات المجدولة على مجدول المهام التلقائي في الخادم (Cron Scheduler). فإذا لم يتم تحديث الأسعار في الموعد المحدد، فاطلب من مسؤول الخادم التأكد من تشغيل المجدول. راجع [المهام المجدولة](../getting-started/scheduled-tasks.md).

## تحديث الأسعار الآن

1. انتقل إلى **الإعدادات >> أسعار الصرف** (Settings >> Exchange Rates).
2. انقر على **تحديث سعر الصرف** (Update Exchange Rate).

سيتم جلب أحدث أسعار الصرف من الخدمة الافتراضية على الفور. كما يمكنك إدخال وتعديل سعر صرف أي عملة يدوياً من الشاشة نفسها؛ راجع [أسعار الصرف](../settings/exchange-rates.md).
