# إدارة الملفات

تُخزّن الملفات المرفوعة، مثل صور المنتجات وبانرات الفئات وشعارات المتجر، على قرص الخادم المحلي بشكل افتراضي. إذا كان متجرك يعمل عبر خوادم متعددة أو كنت تفضل الاحتفاظ بالملفات على خدمات التخزين الكائني السحابي (Object Storage)، فيمكنك تخزينها في Amazon S3 أو Cloudflare R2 بدلاً من ذلك. تتألف مجموعة **إدارة الملفات** (File Management) من ثلاث شاشات، وتنطبق كافة إعداداتها على المتجر بأكمله.

## عام

1. انتقل إلى **التكوين >> إدارة الملفات >> عام** (Configure >> File Management >> General).
2. في قسم **الإعدادات** (Settings)، حدد **مشغل التخزين الافتراضي** (Default Storage Driver).
3. انقر على **حفظ التكوين**.

<ImagePopup src="/images/configure/file-management-general.png" alt="شاشة عام في مجموعة إدارة الملفات مع حقل مشغل التخزين الافتراضي" />

**مشغل التخزين الافتراضي (Default Storage Driver):** يحدد المكان الذي يتم فيه حفظ الملفات المرفوعة الجديدة وعرضها منه:

- **ملف (تخزين محلي) / File (Local Storage)** – القرص الصلب الخاص بالخادم. وهو الخيار الافتراضي.
- **Amazon S3** – حاوية تخزين على Amazon S3، أو أي خدمة تخزين كائني متوافقة مع واجهة S3 API. يجب ضبط إعداداتها في شاشة **Amazon S3** أولاً.
- **Cloudflare R2** – حاوية تخزين على Cloudflare R2. يجب ضبط إعداداتها في شاشة **Cloudflare R2** أولاً.

تعرض بطاقة **التخزين (Storage)** في شاشة [حول النظام](./about.md) المشغل المستخدم حالياً.

### الملفات المرفوعة مسبقاً لا تنتقل تلقائياً

يؤدي تغيير مشغل التخزين إلى تغيير وجهة حفظ الملفات **الجديدة** فقط. أما الملفات التي رُفعت سابقاً فتبقى في مكانها القديم، بينما سيبحث المتجر عنها في وحدة التخزين الجديدة، لذا احرص على نسخ ونقل الملفات السابقة إلى التخزين الجديد قبل إجراء التبديل، لضمان عدم اختفائها من واجهة المتجر.

## خدمة Amazon S3

1. انتقل إلى **التكوين >> إدارة الملفات >> Amazon S3** (Configure >> File Management >> Amazon S3).
2. في قسم **الإعدادات** (Settings)، أدخل البيانات الموضحة في الجدول أدناه.
3. انقر على **حفظ التكوين**.

<ImagePopup src="/images/configure/file-management-s3.png" alt="شاشة Amazon S3 في مجموعة إدارة الملفات مع بيانات اعتماد تجريبية" />

| الإعداد | وظيفته |
|---|---|
| **معرف مفتاح الوصول (Access Key ID)** | معرف مفتاح الوصول للحساب الذي يملك حاوية التخزين (Bucket). |
| **مفتاح الوصول السري (Secret Access Key)** | المفتاح السري المقترن بمعرف مفتاح الوصول. |
| **المنطقة (Region)** | المنطقة الجغرافية التي أُنشئت فيها الحاوية، مثل `us-east-1`. |
| **الحاوية (Bucket)** | اسم حاوية التخزين التي تُحفظ فيها الملفات. |
| **الرابط (URL)** | عنوان الويب الذي تُعرض منه الملفات للزوار. اتركه فارغاً لاستخدام العنوان الافتراضي للخدمة. |
| **نقطة النهاية (Endpoint)** | يلزم فقط عند استخدام خدمات أخرى متوافقة مع S3 (مثل الخدمات المستضافة ذاتياً). اتركه فارغاً لخدمة Amazon S3 الأصلية. |
| **استخدام نقطة نهاية بنمط المسار (Use Path Style Endpoint)** | فعّله للخدمات المستضافة ذاتياً التي تصل للحاويات عبر المسار بدلاً من النطاق الفرعي. يكون معطلاً افتراضياً. |

تُستخدم هذه الإعدادات فقط عندما يكون **مشغل التخزين الافتراضي** معيناً كـ **Amazon S3**. وفي حال ترك أي حقل فارغاً، تُستخدم القيمة من ملف بيئة الخادم (.env) إن وُجدت.

## خدمة Cloudflare R2

1. انتقل إلى **التكوين >> إدارة الملفات >> Cloudflare R2** (Configure >> File Management >> Cloudflare R2).
2. في قسم **الإعدادات** (Settings)، أدخل البيانات الموضحة في الجدول أدناه.
3. انقر على **حفظ التكوين**.

<ImagePopup src="/images/configure/file-management-r2.png" alt="شاشة Cloudflare R2 في مجموعة إدارة الملفات مع بيانات اعتماد تجريبية" />

| الإعداد | وظيفته |
|---|---|
| **معرف الحساب (Account ID)** | معرف حساب Cloudflare التابعة له حاوية التخزين. يُبنى عنوان R2 منه تلقائياً دون الحاجة إلى تحديد نقطة نهاية (Endpoint). |
| **معرف مفتاح الوصول (Access Key ID)** | معرف مفتاح الوصول لرمز R2 API Token. |
| **مفتاح الوصول السري (Secret Access Key)** | المفتاح السري المقترن بمعرف مفتاح الوصول. |
| **الحاوية (Bucket)** | اسم حاوية R2 التي تُخزن فيها الملفات. |
| **الرابط العام (Public URL)** | عنوان الويب الذي تُعرض وتُخدم الملفات من خلاله، سواء كان عنوان r2.dev العام أو نطاقاً مخصصاً (Custom Domain). تكون حاويات R2 خاصة حتى تقوم بتمكين الوصول العام أو ربط نطاق مخصص في Cloudflare. أدخل هذا العنوان هنا لتتمكن من الوصول للملفات. |

تُستخدم هذه الإعدادات فقط عندما يكون **مشغل التخزين الافتراضي** معيناً كـ **Cloudflare R2**. وفي حال ترك أي حقل فارغاً، تُستخدم القيمة المحددة في ملف بيئة الخادم (.env) إن وُجدت.

## الفروقات في Bagisto 2.4

لا يحتوي إصدار Bagisto 2.4 على قسم **إدارة الملفات**.
