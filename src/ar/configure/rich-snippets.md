# البيانات المنظمة والمقتطفات المنسقة (Rich Snippets)

المقتطفات المنسقة (Rich Snippets) هي بيانات منظمة ومُهيأة برمجياً وفق معايير Schema تُضاف تلقائياً إلى صفحات واجهة متجرك، مما يمكّن محركات البحث (مثل Google) من فهم محتوى الصفحات بعمق وعرض تفاصيل جذابة ومميزة — مثل السعر، أو التقييمات، أو التوفر في المخزون — مباشرة ضمن نتائج البحث. تُطبق هذه الإعدادات على مستوى المتجر بأكمله.

## المنتجات (Products)

تُضاف البيانات المنظمة الخاصة بالمنتج تلقائياً إلى كل صفحة منتج. وتتضمن دائماً اسم المنتج، ووصفه، ورابطه، وتتيح لك خيارات التبديل أدناه تضمين بيانات إضافية.

1. انتقل إلى **التكوين >> الكتالوج >> المقتطفات المنسقة (Configure >> Catalog >> Rich Snippets)**.
2. في قسم **المنتجات (Products)**، قم بتفعيل خيار **تفعيل (Enable)**.
3. قم بتفعيل الخيارات والتفاصيل الإضافية التي ترغب في تضمينها وفقاً للجدول أدناه.
4. انقر على **حفظ التكوين (Save Configuration)**.

| الإعداد | ما يضيفه لبيانات محركات البحث |
|---|---|
| **عرض رمز المنتج (Show SKU)** | رمز المنتج التعريفي (SKU). |
| **عرض الوزن (Show Weight)** | وزن المنتج المسجل. |
| **عرض الفئات (Show Categories)** | أسماء التصنيفات والفئات التي ينتمي إليها المنتج. |
| **عرض الصور (Show Images)** | روابط صور المنتج بدقة عالية. |
| **عرض المراجعات (Show Reviews)** | المراجعات المعتمدة للمنتج، مع اسم كل مراجع وتقييمه. |
| **عرض التقييمات (Show Ratings)** | متوسط تقييم المنتج وإجمالي عدد المراجعات. |
| **عرض العروض (Show Offers)** | سعر المنتج بالعملة المعروضة بها الصفحة. بالنسبة للمنتجات القابلة للتهيئة أو متعددة الخيارات، يُعرض أدنى سعر متوفر. |

## التصنيفات (Categories)

1. انتقل إلى **التكوين >> الكتالوج >> المقتطفات المنسقة (Configure >> Catalog >> Rich Snippets)**.
2. في قسم **التصنيفات (Categories)**، قم بتفعيل خيار **تفعيل (Enable)**. تصف صفحات التصنيفات حينها متجرك لمحركات البحث كبنية موقع ويب متكاملة (WebSite Schema).
3. قم بتفعيل خيار **عرض حقل البحث (Show Search Input Field)** لتضمين بنية البحث الداخلي للمتجر (Sitelinks Searchbox)، مما يمكّن محركات البحث من عرض مربع بحث مخصص لمتجرك مباشرة في نتائج البحث.
4. انقر على **حفظ التكوين (Save Configuration)**.
