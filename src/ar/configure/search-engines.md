# محركات البحث (Search Engines)

يعتمد البحث عن المنتجات في واجهة المتجر ولوحة التحكم افتراضياً على قاعدة البيانات. أما بالنسبة للمتاجر ذات الكتالوجات الضخمة التي تحتوي على آلاف المنتجات، فيمكنك ربط عنقود Elasticsearch (Elasticsearch Cluster) فائق السرعة وتحديد نطاق استخدامه. تتضمن مجموعة **محركات البحث (Search Engines)** شاشتين: **عام (General)** و**Elasticsearch**، وتُطبق جميع الإعدادات فيهما على مستوى المتجر بأكمله.

## الإعدادات العامة (Settings)

1. انتقل إلى **التكوين >> محركات البحث >> عام (Configure >> Search Engines >> General)**.
2. في قسم **الإعدادات (Settings)**، قم بتفعيل خيار **تفعيل محرك البحث الخارجي (Enable External Search Engine)**؛ سيظهر خيار **محرك البحث الافتراضي (Default Search Engine)**.
3. حدد **محرك البحث الافتراضي (Default Search Engine)**: إما **قاعدة البيانات (Database)** (وهو الافتراضي) أو **Elasticsearch**.
4. انقر على **حفظ التكوين (Save Configuration)**.

**تفعيل محرك البحث الخارجي (Enable External Search Engine):** عند تعطيل هذا الخيار، تعتمد كافة عمليات البحث على قاعدة البيانات مباشرة بغض النظر عن باقي الخيارات. يكون معطلاً افتراضياً.

**محرك البحث الافتراضي (Default Search Engine):** المحرك المستخدم في أي وضع بحث تم تركه على خيار **استخدام الافتراضي (Use Default)** أدناه. إذا كان مضبوطاً على **قاعدة البيانات (Database)**، فستعتمد كل عمليات البحث على قاعدة البيانات أياً كانت أوضاع البحث الفرعية.

## المنتجات (Products)

1. انتقل إلى **التكوين >> محركات البحث >> عام (Configure >> Search Engines >> General)**.
2. في قسم **المنتجات (Products)**، حدد **وضع بحث لوحة التحكم (Admin Search Mode)**.
3. حدد **وضع بحث واجهة المتجر (Storefront Search Mode)**.
4. انقر على **حفظ التكوين (Save Configuration)**.

<ImagePopup src="/images/configure/search-engines-general.png" alt="شاشة عام في مجموعة محركات البحث مع تفعيل محرك البحث الخارجي وتعيين Elasticsearch كمحرك افتراضي" />

**وضع بحث لوحة التحكم (Admin Search Mode):** المحرك المسؤول عن البحث في المنتجات داخل لوحة الإدارة: نتائج البحث في الترويسة، وجدول المنتجات (DataGrid)، وقوائم اختيار المنتجات.

**وضع بحث واجهة المتجر (Storefront Search Mode):** المحرك المسؤول عن تصفح صفحات التصنيفات، وصفحة نتائج البحث، وعمليات البحث الأخرى في واجهة المتجر.

يمكن ضبط كل وضع بحث على: **استخدام الافتراضي (Use Default)** (وهو الافتراضي)، أو **قاعدة البيانات (Database)**، أو **Elasticsearch**. ولا يستخدم أي وضع محرك Elasticsearch إلا إذا كان **محرك البحث الافتراضي** مضبوطاً على **Elasticsearch**. على سبيل المثال، للإبقاء على لوحة التحكم تعمل بقاعدة البيانات مع تشغيل واجهة المتجر على Elasticsearch، عيّن **محرك البحث الافتراضي** على **Elasticsearch** واضبط **وضع بحث لوحة التحكم** على **Database**.

## إعدادات Elasticsearch

1. انتقل إلى **التكوين >> محركات البحث >> Elasticsearch**.
2. في قسم **الإعدادات (Settings)**، اختر نوع **المصادقة (Authentication)**؛ حيث تظهر فقط الحقول التي تتطلبها طريقة المصادقة المختارة.
3. أدخل تفاصيل وبيانات الاتصال الموضحة في الجدول أدناه.
4. انقر على زر **اختبار الاتصال (Test Connection)** للتحقق من صحة البيانات على الشاشة دون الحاجة لحفظها أولاً.
5. انقر على **حفظ التكوين (Save Configuration)**.

<ImagePopup src="/images/configure/search-engines-elasticsearch.png" alt="شاشة Elasticsearch مع المصادقة باسم المستخدم وكلمة المرور وزر اختبار الاتصال" />

| الإعداد | الوظيفة |
|---|---|
| **المصادقة (Authentication)** | طريقة تسجيل دخول المتجر إلى عنقود Elasticsearch: **بدون مصادقة (No authentication)** (الافتراضي)، أو **اسم المستخدم وكلمة المرور (Username and password)**، أو **مفتاح API (API key)**، أو **سحابة Elastic Cloud مع مفتاح API**، أو **سحابة Elastic Cloud مع اسم المستخدم وكلمة المرور**. |
| **المضيفون (Hosts)** | يظهر عند اختيار "بدون مصادقة" أو "اسم المستخدم وكلمة المرور" أو "مفتاح API". عنوان الوصول إلى العنقود، مثل `http://localhost:9200`. افصل بين عناوين المضيفين المتعددة بفواصل. اتركه فارغاً لاستخدام القيمة المحددة في ملف بيئة الخادم (`.env`). |
| **معرّف السحابة (Cloud ID)** | يظهر لطريقتي **Elastic Cloud**. وهو المعرّف السحابي لحسابك في Elastic Cloud. |
| **اسم المستخدم (Username)** | يظهر لطرق المصادقة باسم المستخدم وكلمة المرور. |
| **كلمة المرور (Password)** | تظهر مع حقل اسم المستخدم؛ أدخل كلمة المرور المطابقة. |
| **مفتاح API (API Key)** | يظهر لطرق المصادقة بمفتاح API. |
| **بادئة الفهرس (Index Prefix)** | نص يُضاف في بداية اسم كل فهرس (Index)، مما يتيح لعدة متاجر التشارك في نفس عنقود Elasticsearch دون تداخل البيانات. |
| **الحد الأدنى لطول الاستعلام (Minimum Query Length)** | أقصر نص استعلام يقبله مربع البحث في واجهة المتجر، من `0` إلى `255`. القيمة الافتراضية هي `0`. |
| **الحد الأقصى لطول الاستعلام (Maximum Query Length)** | أطول نص استعلام يقبله مربع البحث في واجهة المتجر، من `1` إلى `1000`، وبشرط أن يكون مساوياً أو أكبر من **الحد الأدنى لطول الاستعلام**. القيمة الافتراضية هي `1000`. |

ينطبق حدا طول الاستعلام على مربع البحث في واجهة المتجر بصرف النظر عن المحرك المستخدم.

تظهر نتيجة النقر على **اختبار الاتصال (Test Connection)** مباشرة بجانب الزر:

- **Elasticsearch is available** (الاتصال بـ Elasticsearch ناجح ومتاح)
- **Elasticsearch did not answer** (لم يستجب خادم Elasticsearch)
- **Elasticsearch rejected the credentials** (رفض Elasticsearch بيانات الاعتماد المدخلة)
- **The host answered but is not a supported Elasticsearch server** (استجاب المضيف ولكنه ليس خادم Elasticsearch مدعوماً)
- **The Elasticsearch connection is not configured** (لم يتم إعداد اتصال Elasticsearch بعد)

يظهر أسفل النتيجة عنوان المضيف الذي تم اختباره. وعند استجابة العنقود بنجاح، يظهر رقم إصداره واسم العنقود.

### بناء الفهرس (Build the Index)

لا يُرجع عنقود Elasticsearch سوى المنتجات التي تم فهرستها. ولا تتم فهرسة المنتجات إلا عندما يكون خيار **تفعيل محرك البحث الخارجي** مفعلاً و**محرك البحث الافتراضي** مضبوطاً على **Elasticsearch**. بعد ربط العنقود لأول مرة، اطلب من مدير الخادم تشغيل أمر فهرسة المنتجات (Indexer). ومن تلك اللحظة فصاعداً، تُفهرس المنتجات تلقائياً كلما تم إنشاء منتج جديد أو تحديثه أو حذفه. وإذا كان خادمك يعالج المهام الخلفية عبر الطوابير (Queue)، فيجب أن تكون الطوابير قيد التشغيل لمعالجة هذه التحديثات. راجع [المهام المجدولة](../getting-started/scheduled-tasks.md).

## الفروقات في إصدار Bagisto 2.4

لا يحتوي إصدار Bagisto 2.4 على مجموعة مخصصة باسم **محركات البحث (Search Engines)**؛ بل تتواجد إعدادات **Search Engine** و**Admin Search Mode** و**Storefront Search Mode**، والحدين الأدنى والأقصى لطول الاستعلام، في قسم **البحث (Search)** ضمن **التكوين >> الكتالوج >> المنتجات**. والمحركات المتاحة للاختيار هناك هي **Database** و**Elastic Search**، ويتم ضبط إعدادات الاتصال بـ Elasticsearch عبر ملف بيئة الخادم (`.env`).
